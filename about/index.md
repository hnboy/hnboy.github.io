# About stay foolish stay hungry

`stay foolish stay hungry` is a personal technical blog written by **WQ** (hnboy), an electronics engineer working on NAND flash memory, embedded systems, and Linux desktop tooling.

## What you'll find here

- **Hardware & Storage**: ONFI spec notes, NAND signal integrity, HBM/HBF packaging, PCIe/NVMe integration
- **Embedded Linux**: Arch Linux setup, KDE/Wayland tips, package management (pacman, yay, Docker)
- **Web Development**: TypeScript, schema validation (Zod), and tooling for technical writing

Most articles started as my own working notes. I publish them in the hope they help other engineers who run into the same problems.
